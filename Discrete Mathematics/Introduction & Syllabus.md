**Mathematics** is systematic study of patterns, numbers, quantities, structures, logical relationships, etc using abstract reasoning and rigorous proofs to understand how things work.

**Discrete Mathematics** is a branch of mathematics that focuses on distinct, separate, and countable objects (Discrete objects) like integers, graphs, and logical statements. rather than smooth, continuous curves or real numbers.

**Discrete** means separate, distinct, or individually distinguishable elements. while **Continuous** elements are not distinguishable and contains range.

for example : consider two sets `A = {1, 2, 3, 4, 5}` and `B = [1,5]`.
Set A contains exactly 5 values (discrete), while Set B contains every real number between 1 and 5, e.g. 1, 1.5, 3.14, and infinitely many more values (continuous).

Discrete mathematics is foundation of computer science because, computers works on countable quantities.
- A bit can be 0 or 1.
- A graph consist of vertices and edges.
- A database stores individual records.
- A program operates on discrete instructions.

>**Note** : computer can work with continuous values but by using discrete encoding.
