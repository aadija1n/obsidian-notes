
**Transmission Modes** or **Communication Modes** defines the direction of data flow between two devices in a network.

---
### 1. Simplex ( S ---> R )

- Unidirectional / One-Way communication.
  
- Only one can send, and other can receive, but not vice versa.
  
- Uses entire capacity of channel for single direction.
  
- Examples : Keyboard, TV, etc.
### 2. Half-Duplex ( S <---> R )

- Bidirectional but one at a time. I.e. not simultaneous.
  
- Both can send and receive but not at same time.
  
- utilizes full bandwidth for whichever direction is in use.
  
- Example : Walkie-talkie.
### 3. Full-Duplex ( S <===> R )

- Bidirectional + Simultaneous
  
- Both can send and receive at same time.
  
- But the channel capacity is then shared / divided.
  
- Example : modern Ethernet.
