### What is a Computer Network ?

**Computer Network** is a collection of Interconnected devices that communicates with each other to exchange or share data and resources. a computer network consists of -

- **Node** : any device that can send, receive, or forward data.
  
  - **End Systems** : the actual sender and receivers.
    
  - **Intermediate Nodes** : Networking devices that manages network function. I.e. Nodes that deals with forwarding and managing data on the network.
    
- **Links** : The transmission medium between nodes.
  
  - **Wired** : Twisted-Pair, Coaxial, or Optical Fiber.
    
  - **Wireless** : Radio, Microwaves, or Infrared.
    
- **Protocols** - set of rules that define how data packets are formatted, transmitted, received, and acknowledged.
---
### What is Data Communication ?

**Data Communication** - is the process of exchange of data between two or more devices over a medium.

> **Data Communication** is the actual process of transmission of digital or analog data between two devices.
> 
> **Computer Network** is a physical of wireless infrastructure that connects multiple devices.

<br>

There are **5 Main Components** of Data Communication :

1. **Sender** : the node that originate and sends the data.
  
2. **Receiver** : the node that receives the data.
  
3. **Message** : Data that is being transmitted between sender and receiver.
  
4. **Protocols** : set of rules that ensures that the communication is meaningful, for example the format of data must be same on both sender and receiver, otherwise the data will have no meaning. Such concerns are addressed by protocols. Also protocols are responsible for cross-platform communications.
  
5. **Transmission Media (Communication Channel)** : wired or wireless medium.
  

<br>

There are **4 Fundamental Characteristics** of Data Communication that shows the effectiveness of data communication :

1. **Delivery** : ensures that the data is sent to correct and intended destination.
  
2. **Accuracy** : ensures that the data is not altered or corrupted during transmission.
  
3. **Timeliness** : ensures that the data is delivered within intended time.
  
4. **Jitter** : uneven variation in packet arrival. for example 1st packet arrives in 1s, but 2nd packet arrives 4s. This inconsistency in delivery time is called Jitter - It must me minimized as much as possible for better data communication.
