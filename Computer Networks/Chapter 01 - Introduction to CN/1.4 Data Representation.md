**Data Representation** in computer networks is the method of converting human-readable information into binary formats, so that devices can easily transmit it.

---
1. **Numbers** : because numbers are intended for mathematical calculations, they are directly converted to binary (base-10 to base-2). Unlike text, numbers are NOT encoded, instead they are directly converted.
- **Integers** : represented using standard binary, 2's complement (for negative), or unsigned notations.
- **Floating-Point** : real numbers with fractional parts - represented according to specialized standards, such as IEEE 754, dividing bits into sign, exponent, and mantissa.
---
2. **Texts** : are converted into unique bit patterns using encoding like :
- **ASCII** : American Standard Code for Information Interchange, it is and older 7-bit or 8-bit standard representing 128 or 256 basic English characters, numbers, and control symbols.
- **Unicode** : it is the modern global standard, it assigns a unique binary code to virtually every character and emoji across all global languages. It typically uses a variable-length encoding like UTF-8 or UTF-16.
---
3. **Images** : are mapped into a matrix of tiny pixels.
- **Bit Depth** : each pixel is assigned a bit pattern representing its color intensity. for black and white images, its 1 bit per pixel (0 for black, 1 for white).while for high definition RGB colors - 24 bits per pixel. Here is some more on it :
  
  - **1-bit** : Uses 1 bit per pixel to show 2 colors, usually pure black and white.
    
  - **8-bit** : Uses 8 bits per pixel to show 256 colors or shades of gray, often via a color palette.
    
  - **16-bit** : Uses 16 bits per pixel to display "high color" (around 65,536 colors), often split as 5 bits for red, 5 for blue, and 6 for green.
    
  - **24-bit ("True Color")** : Uses 24 bits per pixel (3 bytes) with **8 bits** dedicated to each of the Red, Green, and Blue (RGB) color channels. This produces 16.7 million distinct colors.
    
  - **32-bit** : Uses 24 bits for standard RGB color plus an extra **8-bit alpha channel** for transparency.
    
  - **48-bit and higher** : Uses 16 bits per color channel (Deep Color or HDR) for advanced professional photography and editing.
    
- **Compression** : to reduce the load on network bandwidth, images are transmitted using compressed standard formats like JPEG, PNG, etc.
  

---

4. **Audio** : sound already is analog and continuous in nature. to transmit it in a digital network, it undergoes **Sampling** - measuring the amplitude of the sound wave at thousands of regular intervals every second. These analog measurement are converted into discrete binary values. Which are then represented by formats like MP3, AAC, etc.

---

5. **Video** : it is represented as a collection of images (called frames) synchronized with a continuous audio stream. as videos require very heavy amount of data, network heavily relies on video compression protocols (codecs) like H.264, HEVC, etc. which is then packaged into formats like MP4, MOV, etc.
