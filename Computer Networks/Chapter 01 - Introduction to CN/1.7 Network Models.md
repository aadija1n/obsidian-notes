In Computer Networking, there are certain concerns like :

- **Packetizing Data** : dividing data into smaller chunks, so that is one packet fails - we can re-transmit only that packet and not whole data.
  
- **Common Format** : for cross platform compatibility.
  
- **Signal Conversion** , **Data Access** , and many more concerns.
  

All such concerns are addressed by a Network Model - is a framework that follows a layered approach (Dividing the network into various layers) to address networking concerns. The layered approach helps us for better maintenance and troubleshooting. there are majorly two network models :

1. **OSI Model** ( Theoritical reference model )
  
2. **TCP / IP Model** ( Actually implemented model )
