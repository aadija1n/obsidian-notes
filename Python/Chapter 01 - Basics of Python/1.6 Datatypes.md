**Datatype** determines the kind of object a value represents, which operations are supported on it, and how its behaviour is defined.

The most important principle of python is that -
**In Python, every value is an object / instance of its respective class. and every object has a type. the objects themselves carry some metadata like their types.**

```python
x = 10
print(type(x)) # <class 'int'>
```

We use `type()` function to determine the datatype.

The behaviour of any datatype is defined in its respective class. Python uses **Dunder (Double Underscore) or Magic Methods** to define how a datatype behave when it interacts with functions, operators, and other syntax. for example when you write `x + y`, python translates this into a method call defined inside its respective class. if x and y are integers, it will call `__add__()` from int class (`<class 'int'>`).

---
### Python Objects
- **Numeric** : `int`, `float`, `complex`
- **Boolean** : `bool`
- **Sequence** : `str`, `list`, `tuple`, `range`
- **Mapping** : `dict`
- Set : `set`, `frozenset`
- **Binary** : `bytes`, `bytearray`, `memoryview`
- **Special and user-defined** : `NoneType`, functions, classes, instances, modules, etc.

### Integers (`int`)
`int` is built-in python type for representing integers (numbers with no fractional component). including both negative and positive numbers and 0.
```python
a = 10
b = 0
c = -25
d = 123456789098765433123467753
```

⭐ Unlike many languages, Python integers are not restricted to a fixed 32-bit or 64-bit range, Their precision can grow as needed, subject to available memory and resources. Boolean is a subclass of `int`, but `True` is not an object of int.
```python
print(isinstance(True, int)) # True
print(type(True) is int) # False
```

⭐ Python lets us write integers in several bases :

>**Base 10 ( Decimal )**
>```python
>x = 25
>``` 

>**Base 2 ( Binary )**
>```python
>x = 0b11001
>print(x) # 25
>```
>Prefix : `0b` or `0B`

>**Base 8 ( Octal )**
>```python
>x = 0o31
>print(x) # 25
>```
>Prefix : `0o` or `0O`

>**Base 16 ( Hexadecimal )**
>```python
>x = 0x19
>print(x) # 25
>```
>Prefix : `0x` or `0X`

⭐ Python allows underscores between integers:
```python
print(1_50_400) # prints 150400
print(0b11_00_1) # prints 25
print(0o3_1) # prints 25
print(0x1_9) # prints 25
print(1_000 == 1000) # True

a = 25
b = 0x19
print(a == b) # True
print(a is b) # True
```
underscore do not affect the value, its only for human readability.

```python
x = 1_000 # Valid ✅

x = _1000 # Invalid ❌
x = 1000_ # Invalid ❌
x = 1__000 # Invalid ❌
```

>**Note** : python integer cannot have leading zeros without number formatting, e.g. `025` is invalid in python, but `0o25` is valid.

⭐ Arithmetic Operations on Integer
```python
a = 7
b = 2

print(a + b) # 9 (int)
print(a - b) # 5 (int)
print(a * b) # 14 (int)
print(a ** b) # 49 (int)
print(a // b) # 3 (int) - Floor Division
print(a % b) # 1 (int)
print(a / b) # 3.5 (float)
```

⭐ Floor division on integers : while `/` gives us exact division value, `//` is used for floor division, which gives us the lower round value e.g `3.8` to `3`. and remember that `/` division returns a `float` value, while the `//` floor division gives us a `int` value.
```python
print(9 / 2) # returns 4.5
print(9 // 2) # returns 4
```

even when the division gives us a whole number, `/` still gives a float value :
```python
print(8 / 2) # returns 4.0
```

while floor division for positive numbers rounds towards 0, i.e. lower value. for negative numbers it rounds towards negative infinity, because that is lower :
```python
print(7 // 2) # 3
print(-7 // 2) # -4

print(7 % 2) # 1
print(-7 % 2) # 1
```
