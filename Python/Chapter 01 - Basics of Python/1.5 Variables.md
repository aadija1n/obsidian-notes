A variable is commonly described as a named storage location. However, in python, a more technical way to describe is : " *A variable is a name or label that is assigned to an object in memory.* " and that particularly states that in python - variables do not directly contain values, instead an object such as an integer object or any other datatype's object is created inside memory, and the variable points to it. That is why in python we can reassign a variable easily to different datatypes.

```python
a = 10
b = a
```

Also unlike c, c++, java, etc, python is a dynamically typed language - that means that python variable do not require declaration.
