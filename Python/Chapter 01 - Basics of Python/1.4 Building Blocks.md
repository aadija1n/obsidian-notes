A **Token** is the smallest meaningful unit that can be used in a program.
An **Expression** is a combination of tokens that produces a value such as `10 + 20`.
A **Statement** is also a combination of token, but it is a instruction given to python for execution such as `a = 10 + 20`. so,
- `a = 10 + 20` is a statement.
- `10 + 20` is a expression
- `a`, `=`, `10`, `+`, `20` are tokens.

>Note : if you write `a = 10`, its not a expression because expression must produce a value.

---

An **Identifier** is a name or label assigned to any python object (like variable, function, class, etc) to identify them throughout the program. e.g. `score = 100` , here score is identifier (variable name). It can be more precisely read as " score is an identifier which identifies a variable holding a integer value 100 ". 

>Identifiers are Case Sensitive i.e. `Score = 10` and `score = 20` are two different variables. and also there are some rules for naming and identifier :
>- an identifier can contain only letters (a-z and A-Z), Digits (0-9), Underscore. apart from them anything like special symbols or spaces are not allowed.
>- an identifier can begin with an alphabet or underscore only, it cannot start with a number.
>- Keywords cannot be used as identifiers.
>- an identifier is unique within its scope.
>
>Valid Identifiers ✅ : `name`, `student1`, `student_name`, `_name1` <br>
>Invalid Identifiers ❌ : `2name`, `student@1`, `student name`, `if`, `for`
>
>**Note** : Every variable name is an identifier but not every identifier is a variable name.

Programmers generally use some Naming Convention for different type of identifiers. these conventions are not mandatory or strict rules, but they are used for better code readability.
- PascalCase (e.g. `StudentId`) : generally used for class name.
- camelCase (e.g. `getUser()`) : generally used for function name.
- snake_case (e.g. `student_name`) : generally used for variables and functions.
- UPPER_SNAKE_CASE (e.g. `MAX_SIZE`) : generally used for constants.
- Single leading underscore (e.g. `_password`) : used for non-public / internal names.
- Double leading underscores (e.g. `__balance`) : class attributes that use name mangling.
- Double leading and Trailing underscores (e.g. `__init__`) : special and predefined methods.

---

**Keywords** are reserved words that have special meaning to the language. They have predefined purpose and cannot be used as an identifier. 
Examples : `if`, `else`, `for`, `import`, etc
>To see complete list of keywords for your python version, you can use 'keyword' module.
>
>```python
>import keyword
>print(keyword.kwlist)
>```
