A **Token** is the smallest meaningful unit that can be used in a program.
An **Expression** is a combination of tokens that produces a value such as `10 + 20`.
A **Statement** is also a combination of token, but it is a instruction given to python for execution such as `a = 10 + 20`. 

An **Identifier** is a name or label assigned to any python object (like variable, function, class, etc) to identify them throughout the program. e.g. `score = 100` , here score is identifier (variable name). It can be more precisely read as " score is an identifier which identifies a variable holding a integer value 100 ".

**Keywords** are reserved words that have special meaning to the language. They have predefined purpose and cannot be used as an identifier.
