**Python** is a high-level language that can be used for both programming and scripting. It was developed by **Guido Van Rossum** during 1985-90.
- **As a Scripting Language :** Python does not require a separate compilation step; you can write a few lines of code to automate file cleanups or scrap web data, and an interpreter runs it instantly.
- **As a Programming Language :** Python is a massive, general-purpose ecosystem capable of building large-scale, enterprise-level applications, enterprise backend via Django, complex data science applications, and machine learning models.
<br>

- **Open-Source** : its source code is available under Python Software Foundation License (PSFL).
<br>

- **Programming Paradigms** : Supports Object-Oriented, Functional, and Procedural programming.
<br>

- **Dynamically Typed** : We do not need to specify datatype during variable declaration. The datatype is automatically figured out during runtime.
<br>

- **Automatic Garbage Collection** : The interpreter automatically tracks and delete the objects that are no longer used. I.e. freeing up computer memory on its own. Lets see how python clears memory on its own :
	- **Reference Counting** : python counts how many parts of code point to an object, if the count becomes zero, the object is deleted from the memory.
	- **Circular Reference Handler** : some objects point to each other and create a loop, this loop keeps the count above zero. Python runs a separate background tracker to find and clear these loops.
	- **Generational Collection** : python groups objects by age, it checks newer objects more often than older ones to save processing time.
<br>

- **Indentation** : python uses spaces or tabs to define code blocks, like in c, c++, etc we used {}.
<br>

- **Execution Modes** : python supports two types of execution modes :
	- **Interactive Mode** : each line is written and executed at same time in a Read-Eval-Print Loop (REPL) shell. Provides immediate result or feedback after pressing enter. Code is not saved in any file and it vanishes once you close the shell. Type “python” or “python3” in your terminal to start this mode.
	- **Script Mode** : Source code is written in a .py file and the whole file is executed. Result or feedback is displayed only when the complete file/script runs. The code is permanently saved in a source file.
<br>

- **Cross-Platform** : python is considered both platform (OS) and hardware independent due to PVM and bytecode execution. But only if we don’t use OS specific commands or pre-compiled C based libraries.
<br>

- **PEP (Python Enhancement Proposal)** : is a formal document that proposes a new feature in python. Anyone in the open-source community can draft a PEP. There are three main types of PEP :
	- **Standards Track** : used for adding new features or change in core language.
	- **Informational** : used for guidelines or suggesting best practices for the community.
	- **Process** : proposes a change in workflow and governance rules.
<br>

- **Python IDLE (Integrated Development and Learning Environment)** : is a built-in code editor that comes packaged with standard python installations. IDLE is developed in python itself using the tkinter gui library. IDLE contains a python shell (REPL) for interactive mode and a file editor for script mode.
<br>

- **Interpreted Language** : an interpreter reads and executes the code line-by-line. No .exe formed.
>**Note** : python is NOT a purely interpreted language, it uses a hybrid approach. It uses both compilation and interpretation. But the compilation is done implicitly, that is why we generally regard python as interpreted.
