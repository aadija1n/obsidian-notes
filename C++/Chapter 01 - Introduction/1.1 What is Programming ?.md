A **program** is a collection of instructions (It is not the set of instructions - As sets have unique identities, but a program can have duplicate syntax). A program is written in Programming Language. Programming Languages can be classified into : 
> - On the basis of Level of Abstraction
> 	1. **Low Level Languages** : Closer to machine level
> 		- Machine language (1st Gen) : Binary; 0-0v | 1-5v, No translation required.
> 		- Assembly Language (2nd Gen) : It uses several mnemonics like ADD, SUB, MUL. Requires Assembler to convert into machine code; Used in writing device drivers.
> 	2. **Middle Level Languages** : Its readability is similar to HLL, but the hardware interaction is similar to LLL. Allows direct memory access via Pointers. Example - C, C++.
> 	3. **High Level Languages** : (3rd Gen) Closer to human understanding. Examples - BASIC, COBOL, Fortran, Java, Python etc.
> 	4. **4th Gen Languages** : made for Minimum Input but Maximum Output. Eg. SQL, VB. These consume more memory and are less efficient than HLL.
> 	5. **5th Gen Languages** : Mostly used for AI and future tech. Example - LISP, PROLOG.

> - On the basis of writing and logic
> 	1. **Procedural Programming** : Code is written as a sequence of steps, routines, or functions that manipulate global data. It follows a top-down, step-wise approach. Eg. C, Pascal.
> 	2. **Object-Oriented Programming (OOP)** : Code is written around "objects" that bundle both data and the behaviors (methods) that act on that data. Eg. Java, C#.
> 	3. **Functional Programming** : Writing programs based on mathematical functions. Eg. Scala.
> 	4. **Scripting Languages** : Code is interpreted at runtime. used to automate tasks or power dynamic web content. Eg. Javascript, Python.
> 	5. **Logic/Declarative Programming** : Developers write a series of facts and rules. The computer then uses logical inference to solve problems. Eg. PROLOG.

Every programming language has 2 basic components : 
1. **Libraries** : Set of predefined functions.
2. **Language Translators** - Compiler, Assembler, Interpreter.
