A **program** is a collection of instructions (It is not the set of instructions - As sets have unique identities, but a program can have duplicate syntax). A program is written in Programming Language. Programming Languages can be classified into : 
- On the basis of Level of Abstraction
	- **Low Level Languages** : Closer to machine level
		- Machine language (1st Gen) : Binary; 0-0v | 1-5v, No translation required.
		- Assembly Language (2nd Gen) : It uses several mnemonics like ADD, SUB, MUL. Requires Assembler to convert into machine code; Used in writing device drivers.
